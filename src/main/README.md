# Основная часть проекта GlamourEssence

В данной папке находятся основные файлы веб-приложения интернет-магазина косметики GlamourEssence.

Состав проекта:

* `index.html` — структура и содержимое веб-страницы.
* `style.css` — оформление и стили интерфейса.
* `app.js` — JavaScript-код для реализации интерактивных элементов.

Проект предназначен для демонстрации интерфейса интернет-магазина косметики.
