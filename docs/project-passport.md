# Паспорт проекта GlamourEssence

## 1. Общая информация

**Название проекта:** GlamourEssence.

**Тип проекта:** веб-приложение интернет-магазина косметики.

**Назначение:** предоставление пользователям возможности просматривать каталог косметических товаров и взаимодействовать с интерфейсом интернет-магазина.

## 2. Целевая аудитория

Пользователи, заинтересованные в выборе и приобретении косметической продукции.

## 3. Используемые технологии

* HTML — создание структуры веб-страницы.
* CSS — оформление интерфейса.
* JavaScript — реализация интерактивных элементов.
* Telegram Web Apps API — интеграция с Telegram.

## 4. Основные функциональные возможности интерфейса

* Просмотр каталога косметики.
* Поиск и фильтрация товаров.
* Добавление товаров в корзину.
* Добавление товаров в избранное.
* Просмотр заказов.
* Переход к оформлению заказа.

## 5. Структура проекта

* `index.html` — структура веб-приложения.
* `style.css` — стили и оформление.
* `app.js` — логика интерактивных элементов.

## 6. Цель разработки

Создание удобного и понятного интерфейса интернет-магазина косметики GlamourEssence с возможностью дальнейшего развития функциональности.
